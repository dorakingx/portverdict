# Submission materials

This directory contains a truth-preserving handoff for the Devpost submission. Draft text is ready, public replay screenshots are captured from the production deployment, and the testing path is reproducible.

- `devpost-draft.md` — English submission copy with explicit live-evidence placeholders.
- `testing-instructions.md` — no-login judge path and local verification.
- `video-script.md` — 2:45 target script and shot list; sponsor proof slots remain blocked.
- `final-checklist.md` — exact remaining human and credential gates.
- `screenshots/` — actual Vercel production screenshots, not mockups.

Do not remove `[BLOCKED — LIVE EVIDENCE REQUIRED]` markers or publish the final video until the corresponding authenticated records exist. Devpost submission also requires the entrant's legal attestations and a final review.
